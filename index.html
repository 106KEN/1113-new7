問 AI（其他問題）

a. 這個產品怎麼用？

  1. 在 LINE 圖文選單點中間的「AI 客服」，會開啟這個問答頁。
  2. 選出發月份和地區，綠點是最佳、黃點可去、紅點建議避開。
  3. 點任何一個國家，看 12 個月適合度、跟團與自由行的概估費用。
  4. 想問別的，在「問 AI」輸入問題；在 LINE 聊天室直接傳訊息也可以。

費用怎麼算

以台灣出發、標示天數、一般等級住宿估算，不含簽證、小費、個人購物，旺季與節日會更高。

b. 發現問題，怎麼回報？

GitHub 回報會開啟新 Issue 並帶入你寫的內容；需要協助可在 repo 裡邀請協作者一起處理。
